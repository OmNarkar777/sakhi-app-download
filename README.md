# Sakhi — test app download

**Sakhi** is a mutual-fund savings app for first-time investors, in Hindi, Tamil
and English. You can set goals like *Ghar* or *Padhai*, start a ₹250 SIP, and
follow your money step by step.

This page has the **Android test app** only. There is no source code here.

## ⚠️ TEST BUILD — synthetic data only

- Everything inside the app is **sample data**. No real money moves, and no real
  KYC, bank or exchange is connected.
- **Never enter your real PAN, Aadhaar, bank account or real phone number.**
  Use made-up values. The app shows a "TEST BUILD" notice to remind you.
- Test accounts are **shared**: anyone who types the same phone number gets the
  same account. Don't put anything private in it.

## Download

Go to **[Releases](../../releases/latest)** and tap the file
**`Sakhi-Test-demoNN.apk`** (about 50 MB or less).

## Install (Android)

1. Tap the downloaded file (or open **Files → Downloads** and tap it).
2. If Android asks, allow **"Install unknown apps"** for your browser, then go back.
3. If **Google Play Protect** warns you, tap **More details → Install anyway**.
   (It warns because this test app isn't from the Play Store.)
4. **Already have an older Sakhi test app?** Uninstall it first. Each test
   build is signed differently, so it can't update in place.

## Log in

1. Open the app and pick your language.
2. Enter **any made-up 10-digit mobile number starting with 6, 7, 8 or 9**,
   for example `9811100123`. Please don't use your real number.
3. OTP: **`777777`** (no SMS is sent; every test login uses this code).

The test server sleeps when nobody is using it. **The first login can take up
to a minute.** If it fails, wait a moment and try again.

## What to try

- Do the 5-step KYC with made-up details (for example PAN `ABCDE1234F`).
- Answer the 5 risk questions.
- Create a goal and look at the suggested funds.
- Start a ₹250 SIP (UPI handle `sakhitest.mf@validbank`).
- Check the notifications bell, your profile and the "Your money and your data" page.
